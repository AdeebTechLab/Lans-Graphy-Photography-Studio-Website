4. Why We Made Separate HTML Files (Multi-Page Architecture)

Instead of cramming everything into one cluttered single-page application (SPA), we used a Multi-Page Architecture (MPA) for clear technical reasons:

  • Real-World Client Experience: Clients looking specifically for Wedding packages or the studio location can bookmark, link, and directly share packages.html or contact.html.
  • SEO Ranking: Each page has its own tailored <title> and meta description, allowing Google to rank individual pages for terms like "Wedding photography packages" or "Commercial product studio".
  • Code Maintainability: Clear separation of concerns; changes to the pricing matrix cannot break the portfolio gallery or contact form scripts.
  • Performance: Fast initial page load because the browser only loads assets needed for the current page.

6. Why the Admin Panel is Separate & Protected

In professional web engineering, an administrative backend must never be visible to the general public.

Reasons for Complete Separation:
  1. Confidentiality & Privacy: Regular website visitors should not see other clients' full names, private phone numbers, home/venue addresses, or personal budgets.
  2. Financial Discretion: The React dashboard calculates the studio's total pipeline revenue and booking values. Competitors and casual visitors should not have access to studio revenue metrics.
  3. Action Integrity: Status changes (e.g., "Approve", "Mark Completed", "Delete") must be restricted exclusively to the Studio Director.
  4. Clean Client Navigation: The public navbar focuses on client actions (Home, About, Portfolio, Services, Packages, Contact, Book Session).

How the Admin Panel Works (admin.html):

  • Separate Route: Accessible only by navigating directly to admin.html.
  • Hidden from Search Engines: Includes <meta name="robots" content="noindex, nofollow"> so Google will not index the portal.
  • Security Gateway: Visitors see a restricted Studio Director login screen. No booking data is rendered until correct credentials are supplied.
